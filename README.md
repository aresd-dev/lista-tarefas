# Lista de tarefas

Aplicação Next.js (App Router) com testes unitários usando Jest e Testing Library.

## Instalação

npm install

## Executar em desenvolvimento

npm run dev

## Rodar os testes

npm test

## Deploy

https://<https://lista-tarefas-bnalwz612-ares-projects-8460dcad.vercel.app>

## CI/CD

A cada push ou pull request na branch main, o GitHub Actions roda lint, testes e build automaticamente (arquivo `.github/workflows/main.yml`). A cada push direto na main, depois que tudo passa, a aplicação é publicada automaticamente no Vercel.

## Versão do Next.js

Este projeto foi desenvolvido com Next.js 16 (versão mais recente disponível), mantendo os mesmos conceitos de Server/Client Components e App Router propostos originalmente para Next.js 15.
